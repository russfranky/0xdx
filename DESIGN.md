# DESIGN.md

Design rules for this repo, learned from the owner's corrections. Read this before building or changing UI here. A rule is only added when the owner corrects something; each one carries his words and the date.

## Layout

- **Labels in tab and step strips (the Hero stage tabs, wizard steps, filter tabs) never wrap. Shrink the type size and the letter tracking at small widths before ever allowing a second line.**
  Why: a wrapped tab reads as a bug and breaks the strip's rhythm. *(why inferred, rule approved by the owner 2026-11-13)*

## Copy

- **Labels use plain everyday words, never spec jargon. A label for a demo or preview still says plainly that it is an example, not live data: "Example Launch Flow", never "Illustrative · Sample Flow".**
  Why: plain words let the owner judge the thing at a glance; jargon hides what it is. The example is still named as an example, so nobody mistakes it for live data.
